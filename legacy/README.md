# 宠物陪伴 · 家庭地图 Avatar 高保真 HTML 交互原型

把真实宠物变成一个实时生活在家庭地图里的数字 Avatar——打开就知道它在哪、在做什么，点一下就能看它、叫它、陪它，并通过家庭设备完成追踪、互动与记录沉淀。

## 运行方式

无需任何依赖或构建，直接用浏览器打开即可：

```
双击 index.html （推荐 Chrome / Edge / Safari）
```

桌面浏览器中会以手机画框（390×844）居中显示，贴近真实 App 观感。

## 目录结构

```
├── index.html        应用外壳 + 所有 screen 容器 + 底部 Tab
├── css/style.css     设计令牌、组件样式、地图/Avatar 动效
└── js/
    ├── state.js      全局状态与模拟数据（房间/设备/宠物/轨迹）
    ├── components.js  toast / 弹层 / 抽屉 / 指令反馈
    ├── map.js        地图渲染、Avatar 移动、行为切换、房间/接力/联动
    ├── build.js      建图流程（上传/手绘/扫描）与设备绑定/管理
    ├── records.js     互动、记录、安全、社交等二级页面
    ├── console.js     模拟数据控制台（演示专用）
    └── app.js        路由、Tab、首页、我的、初始化装配
```

## 底部四 Tab

- 首页：宠物状态卡、快捷互动、今日摘要、异常提醒、AI 日记入口
- 地图：家庭平面图 + 动态 Avatar + 设备点位 + 踪迹抽屉 + 点击互动（核心页）
- 记录：历史行踪、行为识别、声音识别、AI 宠物日记、情绪日报
- 我的：家庭地图/设备管理、虚拟栅栏、走失模式、对话框、宠友、声音、通知权限

## 模拟数据控制台（演示重点）

点击右下角 🎛️ 悬浮按钮唤起，可在演示中实时切换：

- 宠物位置（客厅/主卧/次卧/书房/阳台）→ 地图 Avatar 平滑移动并写入踪迹
- 宠物行为（静止/奔跑/张望/睡觉/进食/喝水/玩耍/停留）→ Avatar 姿态与动效切换
- 房间环境（正常/高温/高湿/低温）→ 触发环境联动
- 触发事件（宠物找人/识别到/投喂完成/饮水/围栏告警）
- 联动事件（建议开空调/切换摄像头/音箱播放主人声音）

## 建议演示脚本（6 条核心旅程）

1. 建图与绑定：我的 → 家庭地图管理 → 上传/手绘/扫描 → 房间命名 → 绑定设备 → 完成
2. 打开地图看到 Avatar：首页 → 地图 → 查看宠物位置与行为
3. 点击 Avatar 直接互动：地图 → 点 Avatar → 看看它 / 叫它 / 播放主人声音
4. 摄像头接力：控制台切换宠物位置 → 触发「切换摄像头」→ 确认切换
5. 环境识别联动：控制台设「高温」→ 触发「建议开空调」→ 确认 → 房间温度回落
6. 历史与 AI 日记：地图踪迹抽屉 → 点某条记录看回放 → 记录页 → AI 宠物日记

## 设计原则

- 地图信息极简：只显示 Avatar + 必要设备点位，说明信息点击展开
- 设备联动以「建议 + 确认」为主，不擅自控制家电
- 互动入口就近：点 Avatar 即可看/叫/陪/喂/奖励
- 所有硬件能力统一以「已发送指令」toast 反馈
